# Independent Audit of the First Manuscript Draft

*Audit scope: `docs/research/manuscript-draft.md` and the saved research artifacts listed in the request. This is an audit report; it does not edit the manuscript or research evidence.*

## 1. Overall readiness assessment

**Readiness: substantial scientific draft, not submission-ready.** The manuscript's core count and default-performance claims are consistent with the 1,040 saved prediction records and the independent audit. The distinctions between pooled estimates and seed means, default and target-labelled operating points, synthetic and field evidence, and complete-run metadata versus missing process provenance are generally handled carefully.

No numeric discrepancy was found in the manuscript's default pooled table. The experiment comprises 520 `(seed, event_id)` episode clusters, each represented under both conditions (520 records per condition; 1,040 records total). The reported forced-choice accuracies and selective-risk arithmetic were recalculated from `episode_predictions.json` and agree with the manuscript. The risk-difference intervals agree with `bootstrap_summary.json`.

Before submission, address the reference completeness issue below; retain the explicit caveats on runtime provenance and target tuning; verify runtime simulator settings; and select a journal format and author metadata. This audit did not establish the exact source revision that produced the run. The saved status is `complete` and all ten configured seeds are listed complete, but the operating-system exit code and runtime source provenance are absent.

## 7. Unresolved issues and author decisions

- The run metadata marks `complete` and lists all ten seeds completed, but no OS exit code was recorded. The exact source revision or source-file hashes used at runtime are also missing.
- The current `confirmatory.json` hash matches the saved run metadata, but this does not identify the code or simulator defaults used at runtime.
- Per-target M4 validation coverage and tuning-grid records are unavailable. The saved same-per-seed threshold pair explains repeated test coverage but not why validation tuning returned the same pair for all three target settings.
- The exact scope and random draw details of fault injection are verifiable in current source, but runtime source provenance remains unverified.
- The faulted 70% infeasibility label and approximately 61.5% ceiling are unsupported by saved validation evidence and must remain flagged, not promoted to findings.
- Ten seed clusters limit what the bootstrap can say about between-seed uncertainty; intervals should remain descriptive. They do not show M4 superiority or matched-coverage benefit.
- The simulator is synthetic and not established as a calibrated Noyyal hydraulic model. No field observations or real-world fault-validation evidence were audited here.
- Author, affiliation, corresponding author, funding, ethics/data statements as required by a venue, and journal formatting remain author decisions.
